神经元与激活函数

深度学习的原子是「神经元」。它简单到可以用一行公式写完， 却包含了整个领域最重要的两个零件：加权求和，和非线性激活。 这一章会告诉你为什么少了后者，再深的网络也只是一条直线。

2.1 从一条直线，到一个会投票的单元

上一章的线性模型 $\hat{y} = wx + b$ 只能处理一个输入特征。但现实任务几乎总是多特征的： 判断房价要看面积、房龄、楼层、地铁距离；判断一张图是不是猫要看几百万个像素。

把单个输入扩展成向量，我们就得到了一个「神经元」：

$$z = \sum_{i=1}^{n} w_i x_i + b = \mathbf{w}^\top \mathbf{x} + b$$ $$a = \sigma(z)$$
$z$ 是加权求和（线性部分），$\sigma$ 是激活函数，$a$ 是这个神经元的最终输出

就这么两行。拆开看，它做了一件非常符合直觉的事：

  • 每个输入 $x_i$ 都配一个权重 $w_i$，表示「这个特征有多重要」。
  • 把「输入 × 重要性」全部加起来，得到 $z$。这就是投票——重要特征投的票多。
  • $b$ 是偏置，表示「这个神经元有多容易被激活」。它相当于给投票设了一个基准线。
  • 最后用 $\sigma$ 把票数压缩到一个合适范围，或者决定要不要「点燃」。
◈用买菜理解偏置 b

假设你在决定「今天要不要出门」。天气好 +1 分，不忙 +1 分，有钱 +1 分。 但每个人的「出门门槛」不一样：外向的人门槛是 0（只要有 1 分就出门）， 宅的人门槛是 3（必须全满足）。这个门槛就是偏置 $b$。

数学上，$b$ 的作用是让决策边界平移。没有 $b$ 的话， 当所有输入都是 0 时输出必然也是 0，模型就被强行绑在了原点上——这几乎总是错的。

2.2 一个真实的历史起点：感知机

1958 年，心理学家 Frank Rosenblatt 造出了感知机（Perceptron）。 它的激活函数是一个硬邦邦的阶跃函数：

$$\hat{y} = \begin{cases} 1 & \text{若 } \mathbf{w}^\top\mathbf{x} + b > 0 \\ 0 & \text{否则} \end{cases}$$

2.3 感知机的死刑判决：XOR 问题

感知机的收敛定理听起来很美好，但它有一个致命的限定词：线性可分。 1969 年，Minsky 和 Papert 在《Perceptrons》一书里指出了一个让整个领域沉寂十年的问题：

最基础的逻辑运算异或（XOR），就是线性不可分的。

XOR 的四个样本。红色是输出 0，蓝色是输出 1。 注意它们位于对角线上——无论怎么画直线，都必然有一蓝一红落在同一侧。

为什么？看这张真值表就明白了：

$x_1$$x_2$XOR 输出直觉
000两个都不真 → 假
011只有一个是真 → 真
101只有一个是真 → 真
110两个都真 → 假

正类在对角线上，负类在另一条对角线上。一条直线最多把平面切成两半， 你没办法让两个对角在同一边、另两个对角在另一边。

⚠这场判决的后果

Minsky 的论证被广泛解读为「单层网络能力有限，多层网络又没法训练」。 加上当时的算力条件，神经网络研究进入了长达十余年的寒冬， 资金转向了符号主义 AI。直到 1986 年反向传播被重新发扬光大，才重新抬头。

但要注意：XOR 并不是死路。只要引入一个隐藏层， 两层感知机就能完美解决 XOR——这正是下一章的内容。

2.4 激活函数：非线性从哪来

现在来看这一章最关键的部分。假设我们把两个神经元首尾相连，中间不加任何激活函数：

$$a_1 = \mathbf{w}_1^\top \mathbf{x} + b_1, \qquad a_2 = \mathbf{w}_2^\top a_1 + b_2$$

代入得：

$$a_2 = \mathbf{w}_2^\top(\mathbf{w}_1^\top \mathbf{x} + b_1) + b_2 = \underbrace{(\mathbf{w}_2^\top\mathbf{w}_1^\top)}_{\text{还是个向量}}\mathbf{x} + \underbrace{(\mathbf{w}_2^\top b_1 + b_2)}_{\text{还是个标量}}$$

看出问题了吗？两个线性函数叠在一起，结果仍然是线性函数。 无论你堆多少层，只要能合并成 $\mathbf{w}'\mathbf{x} + b'$，整个网络的能力就等于一个线性模型。 加层数完全是白费力气。

全书最重要的一个结论

没有非线性激活函数，深度就等于零。

激活函数的存在，唯一的使命就是「打破线性」。它让每一层都无法被上一层吸收掉， 从而让网络真正拥有了逐层构造复杂函数的能力。 你以后看到任何关于「深度」的讨论，都要记得这一条。

那为什么需要「深度」？因为复杂函数是由简单函数复合出来的。 就像写程序：你不会写一个一万行的 main， 你会把它拆成函数，函数再调用函数。每一层网络就是一层抽象， 底层学边缘和纹理，中层学眼睛和鼻子，高层学「这是一张猫脸」。

为什么 ReLU 是一个分水岭

2011 年前后，ReLU 开始取代 Sigmoid 和 Tanh，这是深度学习能够「变深」的关键之一。 原因有三个：

  1. 不饱和。Sigmoid 的导数最大只有 0.25，而且在两端趋近于 0。 梯度在几十层里连乘，很快就会变成 $0.25^{50} \approx 10^{-30}$——等于消失了。 而 ReLU 在正半轴的导数恒等于 1，梯度可以原封不动地传回去。
  2. 计算便宜。ReLU 就是一次比较运算，比指数运算快得多。
  3. 产生稀疏性。大约一半的神经元输出为 0，网络变得稀疏，有正则化效果。
⚠ReLU 的副作用：神经元死亡

如果一个神经元的加权和永远为负，ReLU 的输出永远是 0，导数是 0， 梯度也永远是 0——这个神经元再也不会被更新了，它「死」了。

常见诱因是学习率太大，一次更新把权重推到了负半轴。 解决办法：降低学习率，或者用 LeakyReLU / GELU 这类负半轴不为零的函数。

那 GELU 为什么又更好？

ReLU 在 $x=0$ 处是一个尖锐的折角，导数从 0 跳到 1。这个不连续让优化稍微有点难受。 GELU 用光滑曲线近似了 ReLU，并且在 0 附近允许一点点负值通过：

$$\text{GELU}(x) = x \cdot \Phi(x) \approx 0.5x\left(1 + \tanh\left(\sqrt{2/\pi}\,(x + 0.044715x^3)\right)\right)$$
$\Phi$ 是标准正态分布的累积分布函数。右边是常用的近似形式，计算更快

可以这样理解：GELU 不是「一刀切」，而是按概率决定要不要让这个输入通过。 输入越负，通过的概率越低，但永远不会精确等于 0。GPT、BERT、LLaMA 系列大多使用 GELU 或它的变体。

自测 · 点开看答案
如果把网络里所有的激活函数都删掉，会发生什么？

整个网络在数学上等价于一个单层线性变换 $\mathbf{w}'\mathbf{x} + b'$。 无论多少层都一样，因为线性函数的复合还是线性函数。 这时的网络只能画超平面，解决不了 XOR，也识别不了图像。 激活函数是「深度」有意义的前提。

偏置 b 到底有什么用？把它去掉行不行？

去掉 $b$，决策边界就被强制穿过原点。只有当你的数据恰好以原点为中心时才没问题， 而现实数据几乎从来不是这样。

举个具体例子：判断邮件是否是垃圾邮件。如果所有特征都是「是否出现某词」， 那么一封什么词都没有的邮件，加权和必然是 0，输出就被固定了。 但现实中一封空白邮件的判断应该由「基准门槛」决定，这个门槛就是 $b$。

为什么 Sigmoid 会导致梯度消失，而 ReLU 不会？

Sigmoid 的导数 $s(1-s)$ 最大只有 0.25，且当 $|x|$ 大时趋近于 0。 反向传播要把每层的导数连乘起来，$0.25$ 乘上 50 次是 $10^{-30}$， 梯度彻底消失，浅层参数收不到任何有效信号。

ReLU 在 $x>0$ 时导数恒为 1，连乘多少次都不衰减， 梯度可以完整地传到最底层。代价是负半轴导数为 0，可能导致神经元死亡。

「神经元死亡」是什么意思？怎么避免？

对一个 ReLU 神经元，如果它的加权和长期为负，输出恒为 0， 导数也恒为 0，梯度下降就再也无法修改它的权重——它永久失效了。 典型诱因是学习率过大，一次更新就把权重推到了负半轴深处。

避免方法：降低学习率、使用 LeakyReLU / GELU / SiLU 这类负半轴非零的激活、 或者用 BatchNorm 稳定输入分布。实际训练中可以通过统计输出恒为 0 的神经元比例来监控。
