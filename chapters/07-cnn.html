第 7 章 · 第三部 结构篇

卷积神经网络

用全连接层处理图像是一种巨大的浪费——它既不知道「相邻像素是相关的」， 也不知道「猫往右移一格还是猫」。 这一章讲卷积：一种把图像的先验知识直接写进网络结构的方法， 它用极少的参数就超越了人类手工设计的特征。

⏱ 约 28 分钟 🎯 理解卷积、池化、感受野与残差连接 🧪 1 个交互演示

7.1 全连接层的两个致命问题

假设你要做一个图像分类器，输入是 224×224 的彩色图片（3 个通道）。 把它拉平成一个向量，长度是 $224 \times 224 \times 3 = 150{,}528$。

现在接一个只有 1000 个神经元的隐藏层：

$$\text{参数量} = 150528 \times 1000 + 1000 \approx 1.5 \times 10^8$$

一层就是 1.5 亿参数。而且这还只是第一层。问题不只是「参数多」：

❌ 问题一：无视空间结构

把图片拉平，等于告诉网络「第 1 个像素和第 150528 个像素一样远」。 但事实上左上角的像素和它右边的像素高度相关，和右下角的像素几乎无关。 这个信息被完全丢弃了。

❌ 问题二：没有平移不变性

猫在图片左上角时，某个权重学到「这里有个耳朵」。 现在猫移到右下角，同样一只猫，模型完全不认识了—— 它需要为每个位置重新学一遍同样的特征。

卷积要解决的核心问题

图像有两个天然的先验：
① 局部性：有意义的图案（边缘、纹理、眼睛）只占一小块区域。
② 平移不变性：同一个图案出现在哪里都还是那个图案。

卷积把这两条先验硬编码进网络结构里。 这就是为什么它能用 1/1000 的参数做得更好——它把「不需要学的东西」直接省掉了。

7.2 卷积：一个小窗口扫过整张图

卷积的操作简单到可以用一句话说清： 拿一个小矩阵（叫卷积核），在图片上从左到右、从上到下滑动， 每个位置做一次「对应位置相乘再求和」，把结果写进输出。

卷积操作。这个卷积核在做「左右相减」——如果左边亮右边暗，结果是负的； 左边暗右边亮，结果是正的；左右一样亮，结果是 0。所以它能检测出垂直边缘。

7.3 卷积的三个关键性质

① 局部连接（Local Connectivity）

每个输出值只和输入的 $3\times3=9$ 个像素相连，而不是全部 150528 个。 这一下子把参数量从「乘以输入维度」变成了「一个固定的小常数」。

② 权值共享（Weight Sharing）

最精妙的一点：整张图共用同一组 9 个权重。 无论图片多大，卷积核的大小不变，参数量也不变。

这直接解决了平移不变性的问题：既然用的是同一组权重扫描全图， 那么猫出现在左上角还是右下角，激活的都是同一个卷积核—— 模型的响应只是位置变了，特征本身没有变。

方案处理 224×224×3 到 64 通道参数量
全连接150528 → 649,633,856
3×3 卷积3 通道 → 64 通道3 × 3 × 3 × 64 + 64 = 1,792

参数量差了 5000 倍，而卷积的效果通常还更好。 这不是「近似」，而是「用对了结构」带来的降维打击。

③ 多通道与多卷积核

真实图片有 RGB 三个通道，所以卷积核也是三维的：$3 \times 3 \times 3$。 同时我们会用 64 个不同的卷积核，每个负责检测一种模式 （垂直边缘、水平边缘、某种纹理……），输出 64 张特征图。

$$\text{卷积层参数量} = (k_h \times k_w \times C_{in}) \times C_{out} + C_{out}$$
$k_h, k_w$ 是卷积核高宽，$C_{in}$ 输入通道数，$C_{out}$ 输出通道数

7.4 步长、填充与池化

步长（Stride）

窗口每次移动几格。步长 1 保持尺寸，步长 2 让输出尺寸减半——这是一种下采样手段。

填充（Padding）

每次卷积都会让尺寸变小（5→3），几十层之后图就没了。 在图像四周补一圈 0，就能保持尺寸不变。这叫 same padding。

$$H_{out} = \left\lfloor \frac{H_{in} + 2P - k}{S} \right\rfloor + 1$$
$P$ 是填充，$k$ 是卷积核大小，$S$ 是步长。这个公式值得记住，能帮你 debug 形状不匹配

池化（Pooling）

池化是另一种降采样方式。最常用的是最大池化： 在每个 2×2 的区域里取最大值。它没有参数，只是把「这个区域里有没有出现某个特征」 浓缩成一个数。

池化的好处：减少计算量、扩大感受野、提供一点平移鲁棒性 （特征稍微移动几个像素，最大值还是那个最大值）。

✓现代趋势：池化正在被步长卷积取代

很多现代架构（尤其是 ResNet 之后）不再使用池化层， 而是用步长为 2 的卷积来做降采样。

理由：池化没有参数，也就无法学习「怎么降采样最好」； 而步长卷积是可学习的，在数据充足时表现更好。 但最大池化在小数据集上依然很稳，没有过时。

7.5 感受野：神经元到底「看得到」多大范围

感受野（receptive field）是指：输出特征图上的一个点， 对应到原始输入图像上，能「看到」多大的一块区域。

感受野逐层扩大。两个 3×3 卷积堆叠，感受野是 5×5； 三个堆叠是 7×7。层数越深，每个神经元看到的原始图像区域越大。

这就是 CNN 能「从边缘到物体」的原因：

  • 浅层感受野小，只能看到几个像素，学到的是边缘和颜色斑块。
  • 中层感受野扩大到几十像素，学到的是眼睛、轮子、文字笔画。
  • 深层感受野覆盖整张图，学到的是「这是一张猫脸」。
∑为什么用小卷积核堆叠而不是用大卷积核？

两个 3×3 卷积的感受野等于一个 5×5，但参数量的差别很大：

· 一个 5×5：$5\times5 = 25$ 个参数
· 两个 3×3：$3\times3 + 3\times3 = 18$ 个参数

而且中间多了一次非线性激活，表达能力更强。 VGG 网络（2014）正是靠「全部用 3×3」这个设计拿到了当年的最佳成绩。

7.6 残差连接：让 100 层变得可训练

理论上网络越深能力越强。但实践中，把 20 层加到 56 层，训练误差反而变大了。 这不是过拟合（过拟合是训练误差低、测试误差高），而是优化本身失败了。

2015 年，何恺明等人提出了残差连接，用一个极其简单的改动解决了这个问题：

残差连接（Residual Connection）

$$\mathbf{y} = \mathbf{x} + F(\mathbf{x})$$

不再让网络直接学目标映射 $H(\mathbf{x})$，而是让它学残差 $F(\mathbf{x}) = H(\mathbf{x}) - \mathbf{x}$，然后把输入加回去。

为什么这么简单的东西如此有效？有两个互补的解释。

解释一：梯度高速公路

对残差块求导：

$$\frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \mathbf{I} + \frac{\partial F(\mathbf{x})}{\partial \mathbf{x}}$$
$\mathbf{I}$ 是单位矩阵，来自那个恒等映射 $\mathbf{x} \to \mathbf{x}$

看那个 $\mathbf{I}$。梯度里永远有一个恒为 1 的项， 所以哪怕 $\partial F/\partial \mathbf{x}$ 小到接近 0，梯度也能原封不动地传下去。 梯度消失问题被从根上解决了。

解释二：学「什么都不做」很容易

假设第 30 层其实没什么可学的。在没有残差连接时， 它必须学出一个恒等映射 $H(\mathbf{x}) = \mathbf{x}$——这对非线性层来说相当困难。 有了残差连接，它只需要让 $F(\mathbf{x}) \to \mathbf{0}$ 就行了—— 把权重衰减到 0 是最容易不过的事。

所以 「深」不再是负担：多出来的层最差也能学会什么都不做， 不会让结果变差。这就是为什么 ResNet 可以堆到 152 层甚至 1000 层。

注意卷积层的 bias=False：因为后面紧跟 BatchNorm， 而 BatchNorm 本身有可学习的偏移 $\beta$，卷积的偏置就完全多余了。 这是一个常见的小优化，能省下不少参数。

如果输入输出通道数不同，那个 $\mathbf{x}$ 没法直接相加，就用一个 1×1 卷积做投影： identity = self.downsample(x)。

注意最后一行。Vision Transformer（ViT）抛弃了卷积， 把图像切成 16×16 的小块当成「词」，直接喂给 Transformer。 在数据量足够大时，它的表现超过了精心设计的 CNN。

这预示了本书后面要讲的整个故事：当数据足够多时，通用的架构会战胜所有手工设计的先验。 Transformer 就是那个通用架构。

7.8 完整的 CNN 代码

42 万参数，在 MNIST 上能轻松跑到 99% 以上。 作为对比，一个 784→128→10 的全连接网络有 10 万参数，只能到 97% 左右。

🧪三个值得亲手试的实验

1. 把卷积换成全连接。把 conv1 换成 nn.Linear(784, 32*28*28)，参数量会暴涨到 2000 万， 而准确率反而下降。亲手验证「结构比参数重要」。

2. 可视化第一层卷积核。训练完之后把 conv1.weight 的形状 (32, 1, 3, 3) 画成 32 张小图， 你会看到它们自动学成了各种方向的边缘检测器——和你手写的 Sobel 算子惊人地相似。

3. 加一层残差连接。把 conv1/conv2 包成一个残差块， 然后把网络堆到 30 层，对比有无残差连接时的训练曲线。

7.9 本章小结

卷积 convolution
用小窗口扫描输入，每个位置做加权求和。利用局部性和平移不变性。
卷积核 kernel / filter
被共享的小权重矩阵。每个卷积核负责检测一种局部模式。
特征图 feature map
一个卷积核扫过整张图后的输出。值越大表示该位置越像这个模式。
感受野 receptive field
一个神经元能看到的原始输入区域大小。随层数增加而扩大。
步长 / 填充 stride / padding
步长控制滑动间隔（降采样），填充控制输出尺寸（补零保持大小）。
残差连接 residual / skip connection
$\mathbf{y} = \mathbf{x} + F(\mathbf{x})$。为梯度提供恒等通路，让极深网络可训练。
  1. 全连接层处理图像有两个致命问题：无视空间结构、没有平移不变性。
  2. 卷积用局部连接 + 权值共享把这两个先验写进结构，参数量能少 5000 倍。
  3. 输出尺寸公式：$H_{out} = \lfloor (H_{in} + 2P - k)/S \rfloor + 1$。
  4. 感受野随层数扩大，这是 CNN 能「从边缘到物体」的机制。
  5. 残差连接让 100 层变得可训练，它是现代所有深层网络的标配。
  6. ViT 用 Transformer 取代卷积并取得更好效果，预示着「通用架构战胜手工先验」。
自测 · 点开看答案
为什么卷积的参数量和处理图像大小无关？

因为权值共享。无论图片是 224×224 还是 1024×1024， 用的都是同一组 3×3 的权重，只是滑动的次数变多了。

参数量只取决于：卷积核大小、输入通道数、输出通道数。 比如 3×3 卷积把 3 通道变成 64 通道，参数量永远是 $3\times3\times3\times64 + 64 = 1792$，跟输入是 224 还是 1024 完全无关。

这就是「结构先验」的威力：把「同一个图案出现在哪里都是同一个图案」 这个知识直接编码进结构，就不用再从数据里学了。

输入是 32×32，用 5×5 卷积核、步长 1、无填充，输出多大？如果加 2 层填充呢？

用公式 $H_{out} = \lfloor (H_{in} + 2P - k)/S \rfloor + 1$：

无填充：$\lfloor(32 + 0 - 5)/1\rfloor + 1 = 28$。输出 28×28。
加 2 层填充：$\lfloor(32 + 4 - 5)/1\rfloor + 1 = 32$。输出 32×32，尺寸不变。

顺带记住一个常用的经验公式：当 $k$ 是奇数时， 填充 $P = (k-1)/2$ 就能保持尺寸不变（3×3 填 1，5×5 填 2，7×7 填 3）。

两个 3×3 卷积和一个 5×5 卷积，感受野相同，为什么前者更好？

两个原因。第一是参数更少：假设通道数都是 $C$， 5×5 需要 $25C^2$ 个参数，两个 3×3 需要 $2\times9C^2 = 18C^2$，少了 28%。

第二是非线性更强。两个卷积之间可以插入一次 ReLU， 整个函数的表达能力比单个 5×5 卷积（只有一个非线性）更强。 用数学语言说，两个 3×3 构成的函数空间严格大于单个 5×5。

VGG 把这条经验用到了极致：整个网络只用 3×3 卷积和 2×2 池化， 结构极其规整，却拿到了 2014 年的最佳成绩。

残差连接为什么能解决梯度消失？给出数学上的理由。

因为残差块的导数是 $\dfrac{\partial \mathbf{y}}{\partial \mathbf{x}} = \mathbf{I} + \dfrac{\partial F(\mathbf{x})}{\partial \mathbf{x}}$。

关键在于那个单位矩阵 $\mathbf{I}$。无论 $F$ 的导数多小， 梯度里永远保留一个恒为 1 的恒等项，可以无损地传到下一层。

如果堆叠 $L$ 个残差块，总梯度是 $\prod_{l}(\mathbf{I} + \partial F_l/\partial \mathbf{x})$， 展开后包含大量的恒等路径，梯度可以「抄近路」直接从最后一层流回第一层。 这就是为什么它能支撑 152 层甚至 1000 层的网络。

ViT 抛弃了卷积，为什么在数据足够多时还能更好？

卷积的强项是「把先验知识写进结构」，这让它在数据有限时极其高效—— 不需要从数据里学「局部性是重要的」。

但先验也是一种限制。当数据量足够大（比如 JFT-300M 的 3 亿张图）时， 模型有能力自己从数据里学出比「局部性 + 平移不变性」更好的归纳偏置， 这时候硬编码的先验反而成了束缚。

实测结果是：在小数据集（比如 ImageNet 的 100 万张）上，CNN 仍然优于 ViT； 但一旦数据规模上一个数量级，ViT 就反超了。 这个规律贯穿整个深度学习史，也直接引出了后面的大模型时代。
