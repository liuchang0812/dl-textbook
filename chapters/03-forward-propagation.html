多层网络与前向传播

把神经元排成层、用矩阵乘法一次算完，这就是「前向传播」。 这一章会看到两层网络如何解决 XOR，还会遇到一个让人震撼的定理： 只要够宽，一个隐藏层可以逼近任何连续函数。

3.1 一层神经元，就是一个矩阵乘法

上一章我们让一个神经元处理 $n$ 个输入。现在假设有 4 个神经元， 每个都接收同样 3 个输入。如果一个个算，要写四遍公式：

$$\begin{aligned} a_1 &= \sigma(w_{11}x_1 + w_{12}x_2 + w_{13}x_3 + b_1)\\ a_2 &= \sigma(w_{21}x_1 + w_{22}x_2 + w_{23}x_3 + b_2)\\ a_3 &= \sigma(w_{31}x_1 + w_{32}x_2 + w_{33}x_3 + b_3)\\ a_4 &= \sigma(w_{41}x_1 + w_{42}x_2 + w_{43}x_3 + b_4) \end{aligned}$$

写成这样不仅啰嗦，而且没法在 GPU 上并行。关键观察是： 这四个式子结构完全一样，只是系数不同。而这正是矩阵乘法的定义。 把它们摞起来：

$$\underbrace{\begin{bmatrix} a_1\\a_2\\a_3\\a_4 \end{bmatrix}}_{\mathbf{a}\ (4\times1)} = \sigma\!\left( \underbrace{\begin{bmatrix} w_{11}&w_{12}&w_{13}\\ w_{21}&w_{22}&w_{23}\\ w_{31}&w_{32}&w_{33}\\ w_{41}&w_{42}&w_{43}\end{bmatrix}}_{\mathbf{W}\ (4\times3)} \underbrace{\begin{bmatrix} x_1\\x_2\\x_3 \end{bmatrix}}_{\mathbf{x}\ (3\times1)} + \underbrace{\begin{bmatrix} b_1\\b_2\\b_3\\b_4 \end{bmatrix}}_{\mathbf{b}\ (4\times1)} \right)$$
形状检查：$(4\times3)\times(3\times1) = (4\times1)$，维度对得上

也就是一行：

一层网络的统一写法

$$\mathbf{a} = \sigma(\mathbf{W}\mathbf{x} + \mathbf{b})$$

$\mathbf{W}$ 的第 $i$ 行就是第 $i$ 个神经元的全部权重。 整个深度学习，本质上就是反复做这件事：矩阵乘法 → 加偏置 → 非线性。

◈矩阵乘法到底在做什么

别被线性代数的术语吓到。$\mathbf{W}\mathbf{x}$ 做的事情是： 对输出向量的第 $i$ 个元素，取 $\mathbf{W}$ 的第 $i$ 行与 $\mathbf{x}$ 做「对应位置相乘再求和」。

说白了，就是同时算完所有神经元的加权求和。 之所以要用矩阵，是因为 GPU 有几千个核心可以同时做乘加运算—— 矩阵乘法是并行计算最擅长的形状。

3.2 前向传播：一层一层往下算

现在把两层接起来。下面是一个 3 → 4 → 2 的网络：3 个输入，4 个隐藏神经元，2 个输出。

前馈神经网络。「前馈」的意思是信息只往一个方向流动：从左到右，没有回头路。 连接数 = 3×4 + 4×2 = 20 条，每条边对应一个权重。

用矩阵写出来，前向传播只有四行：

$$\begin{aligned} \mathbf{z}^{(1)} &= \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)} &\quad (4\times3)(3) &\to (4)\\ \mathbf{h} &= \sigma(\mathbf{z}^{(1)}) &\quad &\to (4)\\ \mathbf{z}^{(2)} &= \mathbf{W}^{(2)}\mathbf{h} + \mathbf{b}^{(2)} &\quad (2\times4)(4) &\to (2)\\ \hat{\mathbf{y}} &= \text{softmax}(\mathbf{z}^{(2)}) &\quad &\to (2) \end{aligned}$$

上标 $(1)$、$(2)$ 表示「第几层」，不是指数。这是深度学习论文里的通用约定，要习惯。

∑softmax：把分数变成概率

多分类的输出层通常用 softmax，它把任意实数向量变成一个概率分布 （每个值都在 0~1 之间，且总和为 1）：

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

分子用指数是为了拉开差距：大数会变得更大，而且永远是正的。 分母做归一化。第 11 章讲语言模型时，softmax 会出现在每一个词的预测上。

3.3 XOR 是怎么被解决的

回到上一章的悬案。Minsky 说单层网络解决不了 XOR。但如果我们中间加一层隐藏层呢？

思路非常巧妙：把 XOR 拆成两个线性可分的子问题。

  • $\text{XOR}(x_1,x_2) = (x_1 \text{ OR } x_2) \text{ AND NOT}(x_1 \text{ AND } x_2)$
  • 「或」和「与」各自都是线性可分的，一个神经元就能学会。
  • 把两个结果再交给输出层做一个线性组合，就能得到 XOR。

换句话说：隐藏层把原始空间「扭曲」了，让本来不可分的问题在新空间里变得可分。 拖动下面的滑块，看决策区域是怎么从一团模糊变成清晰的棋盘状的：

背景颜色是网络对每个位置的预测（蓝=1，红=0）。两条虚线是两个隐藏神经元的决策边界： 绿线 学会「或」， 橙线 学会「与」。 把它们拖到 100%，蓝色区域正好覆盖左上和右下两个点。

隐藏层的本质

隐藏层不是「中间层」这么简单。它的作用是重新表示数据—— 把输入映射到一个新的坐标系里，在那里原本纠缠在一起的两类样本被拉开了。

这正是「表示学习」（representation learning）这个词的由来。 现代大模型的每一层都在做这件事：把词、句子、概念重新编码成更容易处理的形式。

3.4 通用逼近定理：为什么神经网络「什么都能学」

1989 年，George Cybenko 等人证明了一个让人惊讶的结论：

Universal Approximation Theorem

一个只有单个隐藏层的前馈网络，只要隐藏层神经元足够多， 就可以以任意精度逼近任何定义在紧集上的连续函数。

这个定理听起来像是在说「一层就够了，深度没用」。但实践中完全不是这么回事。 原因在于定理只说「存在」这样的网络，没说：

  • 需要多少个神经元（可能是指数级的多，多到装不下）
  • 怎么找到那组权重（梯度下降可能根本训不出来）
  • 需要多少数据（参数越多，需要的数据越多）
⚠别被定理骗了

「可以逼近」不等于「学得到」。一个宽度 $2^n$ 的单层网络理论上能拟合任何东西， 但你既训练不动它，它也会把所有噪声都背下来。

深度的价值在于「复用」。深层网络可以把简单特征组合成复杂特征， 而每一层都复用了上一层的成果。这带来的效率提升是指数级的： 有些函数用深网络只需要 $O(n)$ 个参数，用浅网络却需要 $O(2^n)$ 个。

一个直观的类比

假设你要计算 $x^{16}$。笨办法是乘 15 次。聪明办法是 $x \to x^2 \to x^4 \to x^8 \to x^{16}$，只乘 4 次。 后者的每一步都复用了上一步的结果，这就是「深度」的威力。

神经网络也是这样：第 5 层不需要从像素重新学起，它直接使用第 4 层已经提取好的特征。 这就是为什么现代大模型动辄上百层，而不是把一个巨大的单层网络摊平。

1. 为什么 softmax 要先减最大值？ 如果 $z$ 里有 1000，$e^{1000}$ 会溢出成 inf。 减去最大值后最大的指数变成 $e^0 = 1$，数学上完全等价，但不会溢出。 这个技巧叫 log-sum-exp trick，你会在几乎每个大模型实现里看到它。

2. 为什么 x @ W1.T 要转置？ 因为我们把 $\mathbf{W}$ 存成「(输出维度, 输入维度)」的形状， 这样每一行就是一个神经元的权重，读起来更直观。这只是约定，不影响数学。

3.6 参数量怎么算

参数量的计算极其简单：连接数 + 偏置数。 对相邻的两层（$n_{\text{in}}$ 个输入，$n_{\text{out}}$ 个输出）：

$$\text{参数量} = n_{\text{in}} \times n_{\text{out}} + n_{\text{out}}$$

用这个公式算几个真实网络，你会对「大模型」的规模有具体的感受：

3.7 批处理：为什么输入是矩阵而不是向量

上面代码里我一直写着 (batch, n_in)。这是实际训练中的关键细节。

你当然可以一次只喂一个样本，但那样 GPU 的几千个核心绝大部分时间在闲着。 正确的做法是把 $B$ 个样本堆成一个矩阵，一次性算完：

$$\underbrace{\mathbf{Z}^{(1)}}_{(B\times 4)} = \underbrace{\mathbf{X}}_{(B\times 3)} \underbrace{\mathbf{W}^{(1)\top}}_{(3\times 4)} + \underbrace{\mathbf{b}^{(1)}}_{(4)}$$
偏置 $\mathbf{b}$ 会自动广播（broadcast）到每一行——这是 NumPy / PyTorch 的语法糖
◈批处理为什么不影响结果

因为每个样本是独立计算的，样本之间没有交互。所以「一次算 32 个」和 「循环算 32 次」在数学上完全等价，只是前者快几十倍。

例外情况：BatchNorm 和注意力机制会跨样本或跨位置交互， 那时候「批量大小」就会真的影响结果了。第 6 章和第 10 章会讲。

批量大小（batch size）是一个需要权衡的超参数：

批量太小

比如 1~8。计算效率低，梯度噪声大，训练过程抖动。但它有时能帮助模型跳出糟糕的局部区域。

批量太大

比如 4096。GPU 利用率高，梯度稳定。但显存吃紧，而且泛化能力有时反而变差，通常需要配合更大的学习率。

常见做法

视觉任务 32~256，语言模型预训练 512~4096（配合梯度累积凑到百万级 token 的全局批量）。

3.8 本章小结

前向传播 forward pass
输入经过每一层的「矩阵乘 → 加偏置 → 激活」，最终得到预测值的过程。
隐藏层 hidden layer
输入和输出之间的层。它把数据重新表示，让原本不可分的问题变得可分。
MLP 多层感知机
由若干全连接层堆叠成的网络。是最基础的深度网络形态。
全连接 fully connected / dense
上一层的每个输出都连到下一层的每个神经元。参数量为 $n_{in}\times n_{out}$。
批量 batch
一次前向传播同时处理的样本数。越大越快，但更吃显存。

用 float32 存储只要不到 1 MB。所以 MNIST 这种任务，算力和显存都完全不是瓶颈—— 这也解释了为什么它是入门练习的标配。

为什么加一个隐藏层就能解决 XOR？用一句话说清楚。

因为隐藏层把输入映射到了一个新的表示空间，在那里两类样本变得线性可分了。

具体到 XOR：隐藏神经元 1 学会「或」（$x_1+x_2 > 0.5$）， 隐藏神经元 2 学会「与」（$x_1+x_2 > 1.5$）。 于是四个样本在新空间里的坐标变成 $(0,0)\to(0,0)$、$(0,1)\to(1,0)$、 $(1,0)\to(1,0)$、$(1,1)\to(1,1)$——现在一条直线就能分开了。

通用逼近定理说「一层就够」，为什么我们还要用几百层？

因为定理只保证「存在」，不保证「可得」。要逼近某些函数，单层网络可能需要 指数级的神经元数量，多到根本装不进显存，也根本训不出来。

深层网络的真正优势是层次化的特征复用：计算 $x^{16}$ 用 $x\to x^2\to x^4\to x^8\to x^{16}$ 只要 4 次乘法，而不是 15 次。 每一层站在上一层的肩膀上，效率是指数级的差别。

为什么 softmax 要先减去最大值？不减去会怎样？

因为 $e^{z}$ 增长极快：$e^{89}$ 就已经超出 float32 的范围，变成 inf。 一旦出现 inf，inf / inf 就是 nan，整个训练直接崩掉。

减去最大值后，最大的指数项变成 $e^0=1$，其余都小于 1，永不溢出。 而因为分子分母同时乘了 $e^{-max}$，结果在数学上完全不变。 这个技巧叫 log-sum-exp，是大模型推理中最基础也最关键的数值稳定手段之一。
