这本书想解决什么问题

市面上讲深度学习的材料，大多卡在两个极端：要么是论文和教科书，一上来就是 $\nabla_\theta \mathcal{L}$ 和雅可比矩阵，程序员读三页就放弃了；要么是「调包教程」， 教你把 model.fit() 敲一遍，跑通了却什么也没懂，遇到问题完全不知道从哪下手。

这本书走第三条路：先把直觉建立起来，再补数学，最后落到代码。 每一个概念都会回答三个问题——它想解决什么问题、它长什么样、它怎么写成代码。 数学只在真正需要的地方出现，而且一定配着一句人话解释。

全书唯一的中心思想

深度学习的全部魔法，可以压缩成一句话： 把「写规则」换成「定义目标 + 自动调参」。

你不再告诉程序「猫有尖耳朵和胡须」，而是告诉它「这张图是猫，那张是狗」， 再给它一个可以衡量「错得多离谱」的数字，剩下的交给梯度下降。 从 1958 年的感知机到 2026 年的大模型，变的只是「目标函数怎么定义」和「参数怎么调得更高效」。

你需要什么基础

必需 · 会写代码

任意一门语言的编程经验，能看懂函数、循环、数组就够了。书中代码用 Python + NumPy + PyTorch。

必需 · 高中数学

知道函数、向量、求和符号 $\sum$ 是什么意思。导数只需要「变化率」这个直觉，第 4 章会从零讲起。

不需要 · 显卡

所有交互演示都在浏览器里跑。想真正训练模型时，一张免费 Colab 或本地 GPU 就够。

不需要 · 线性代数熟练

矩阵乘法会在第 3 章用「一排数字乘另一排数字」的方式讲清楚，不用先学完线性代数。

怎么读这本书

  • 别跳读代码。每一段代码都是能跑的，而且短到可以一行一行看。看懂 20 行 NumPy 比读 20 页公式有用。
  • 遇到 紫色直觉框 时慢下来。那通常是一个概念最关键的地方。
  • 动手玩每一个演示。拖动滑块、把学习率调到发散、把多项式次数拉到 12——破坏它，你才会真的懂它。
  • 看完一章做一次自测。每章末尾的折叠问答是最低成本的自我检查。
  • 随时按 Aa 调字号、按 ☾ 换暗色主题。长时间阅读，舒服比什么都重要。
✓一个建议的节奏

每天一章，21 天读完。第二部分（第 4-6 章）值得花三天——那是全书的承重墙。 第七部分的 mini-GPT 请务必亲手跑一遍，跑通之后你对大模型的恐惧会消失一大半。

符号约定

全书符号统一如下，看到不认识的随时回来查。

符号读作含义
$x$输入一个样本的特征向量，例如一张图的像素
$y$标签 / 目标我们希望模型输出的正确答案
$\hat{y}$y-hat模型实际给出的预测值
$w,\ b$权重、偏置模型里可学习的参数
$\theta$theta所有参数的统称
$z$z线性部分的加权和（激活之前）
$a$a激活之后的输出（activation）
$\sigma$sigmaSigmoid 函数，也泛指任意激活函数
$L$ 或 $\mathcal{L}$损失衡量预测有多错的标量
$\nabla_\theta L$梯度损失对参数的偏导组成的向量
$\eta$ 或 $\alpha$eta / alpha学习率
$\odot$Hadamard 积两个同形状张量逐元素相乘
$d_k$—注意力中 Key 向量的维度
